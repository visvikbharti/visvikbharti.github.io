## Design system

- Colours (`vars.css`): black `--bg`, raised panels `--bg-raise`, 1px rules `--line` / `--line-strong`, text `--fg` / `--fg-muted` / `--fg-dim`, cream `--cream` for primary buttons, neon green `--accent` as the ONLY accent. No purple, pink, gradients, rounded corners, shadows or hover lifts. Text contrast must be >= 4.5:1.
- Type: `--font-mono` (Geist Mono) for headings, nav, labels, buttons, tags and numbers; `--font-sans` (Geist) for body text.
- Components: square `.btn` (cream fill) and `.btn.alt` (outline); `.tech-tag`; 1px-bordered cell grids; section titles get an automatic index ("01 —") via CSS counters; `.video-slot` (`style.css`), a 16:9 YouTube frame (youtube-nocookie) with a 1px rule and a one-line caption. Three video slots are commented out until there is a video: the introduction in the home page's About section, the demo in the RNA Lab Navigator Overview and the poster walkthrough (2 minutes) at the end of the ESTIC page's hero. Each comment says how to show it.
- Canvas art: `hero-cells.js` (tissue, click-to-break, HUD) and `project-art.js` (`.split__img[data-art]` scenes: stats, audit, dna-break, triplex, g4, assembloid, ci, rag; plus `.journey__art[data-art="fold"]` in About: a circuit trace that goes slack, searches at random, and folds into ubiquitin from the real PDB 1UBQ C-alpha trace, as a 16 s story that starts from the beginning when first seen). `robots.js` (hobby page) is a small z-buffered renderer that draws meshes as shaded glyphs with outline edges and replays `assets/hobby/*.json`: MuJoCo and quadsim runs and OpenSCAD meshes exported from the two robot repos (exporter notes in `_handover/hobby-export/`). All of them animate only while on screen, draw a still frame under `prefers-reduced-motion`, and use an integer hash for randomness. `main.js` decodes `.scramble` headlines from DNA letters, or from `data-glyphs` (binary on the hobby page; AUGC on the RNA project pages, digits on StickForStats and Confidence Intervals).
- Subpage heroes: the seven project pages and Publications put the copy and a drawing side by side (`.hero-split`; the drawing below on phones): `<figure class="hero-art">` holds the frame (`aria-hidden`), a one-line `figcaption` that says what the drawing shows, and a Pause button added by the script (none under reduced motion). The project pages use point drawings, deliberately not the home page's characters: `.hero-art__frame[data-points]` with `triplex` (TRIPinRNA), `checks` (StickForStats), `sort` (DNA repair), `g4`, `assembloid`, `ci` and `rag`. Publications uses the character scene `pubs` (`data-art`), which reads the page's own `.publication-item` list (its kind and `data-year`), so a new entry appears in the drawing by itself. The 'stats' scene stacks its checklist above the histogram in panels under 28 text rows. Each page has a `<noscript>` style that hides the empty frame.
- Research stage (`research.html`, `js/point-art.js`): deliberately not the character drawings. One pool of 1,100 points takes each research area's shape in turn and keeps moving in it (a turning RNA triple helix, a turning G-quadruplex with K+ between the tetrads, cells sorted by the repair reporter, an assembloid's neurons with interneurons migrating across it in jumps, a histogram that becomes a Q-Q plot, articles read by a beam), and flies to the next shape in 0.9 s, each point from where it was drawn. Below the full-width `.research-stage__art` come the controls (Pause first, then the arrows and markers, so the Tab order matches what is seen) and the `.stage-slide`s (each names its formation in `data-scene`), stacked in one grid cell so the bar keeps the tallest slide's height (inactive slides are `visibility: hidden`). A marker's 5 s CSS fill is the slideshow's clock (`animationend` moves on); it runs only while the script sets `.is-auto`. Hovering or scrolling the stage away holds it (`.is-paused`). Using a control, the arrow keys on the controls, or keyboard focus entering the stage stops the rotation until Play (the WAI carousel pattern); Pause stops the rotation and the drawing. Under reduced motion each area is a still and changes only on request. The script adds the carousel roles and the "n of 6" slide labels; without JS the slides are a plain list.
- ESTIC page animations (`assets/estic-2026/estic-art.js`, styled in `css/estic.css`): three `<figure class="estic-anim" data-anim="spreads|pubbias|audit">` blocks, each above its static figure and table, which stay (the table is the accessible version of the data). They speak the Research stage's dot language (square dots on black in the greys, `--cream` and `--accent`, 12 px mono labels; the palette and font are read from `vars.css` at run time) but load nothing from `js/` and share no code with `point-art.js`. Each caption says whether the drawing shows data (and its source) or is a simulation. They draw only while at least 20% on screen, the tab visible, not paused and not finished, and show a still under reduced motion (no Pause button; the state buttons switch at once); nothing requests animation frames otherwise. `spreads` is a live simulation of the Student-versus-Welch table: 10 values with SD = ratio and 40 with SD 1 from one true mean, both t-tests, two 100-square waffles for the share of runs with p < 0.05, stopping at 40,000 runs (10,000 for the reduced-motion still); runs are seeded (sfc32, seeds 2026 to 2029) so each ratio gives the same result on every visit, and each frame's simulation is capped at 6 ms so phones keep 60 fps. Its p-values come from jStat's Student t distribution, version 1.9.6, which the script fetches from cdnjs only when the figure is within 700 px of the screen; the URL and its Subresource Integrity hash are the figure's `data-jstat` and `data-jstat-integrity` (for another version take its `sha512` from `api.cdnjs.com/libraries/jstat/<version>?fields=sri`). If jStat is blocked or fails the integrity check the figure is hidden, never shown wrong. The t-test code sits between `/* stats:begin */` and `/* stats:end */` and can be tested alone: it was checked against 3,000 random datasets with 30-digit mpmath p-values (no decision at p < 0.05 differed) and R's `sleep` example; the test scripts are not in the repo. The script reads the table percentages from `#table-false-positives` (the "table below" notes) and `#table-audit-shares` (the audit's 1,000 dots, one for 23 of the 23,000 articles, each group's count the share x 10 rounded: 397, 277, 180, 101, 45), so those two ids stay. `pubbias` draws Turner et al.'s 74 trials: 37 positive and published, 1 positive and not, 22 negative or questionable and not published, 11 published as positive, 3 published as negative. The two stories move between two states with one number (0 to 1): on screen they hold, move, hold and move back; the state buttons go straight to a state and stop the playing until Play (the status line is `aria-live` off while playing, polite otherwise). The script sets each frame's height for the layout it chooses (stacked below 780 px of frame for `spreads`, 600 for `pubbias`, 720 for `audit`, and a compact variant below 340 px); the heights in `estic.css` are the same values before it runs. After changing a drawing check widths from 320 to 1440 px (nothing within 5 px of a frame's edge, no overlapping labels), a clean console, and that nothing requests animation frames when the figures are off screen, paused, finished or under reduced motion.
- Menus: every page's menu, the home page's included, sends Research, Publications, Projects, Hobby and ESTIC 2026 to their pages, and About and Contact to the home page's sections. With eight items the menu is tight: from 769 to 1040 px only the VB mark shows, and up to 860 px the menu also takes the phones' smaller type (`style.css`); after adding an item, check that it still fits at every width from 769 to 1440 px (on phones the menu scrolls sideways). The home page's Research, Publications and Projects sections each end with a button to their page. `pages/about.html` is an older page that no menu links to.
- Scroll reveal (subpages): `main.js` adds `.io-reveal` to the sections' blocks and cards when JS runs and motion is welcome, and removes it once they arrive (or when keyboard focus enters). Its own class name: `hobby.html` has a separate `.reveal` (`hobby.css`, `robots.js`).
- Accessibility: skip links and `<main>` on every page; decorative canvases `aria-hidden` (a drawing's visible caption stays readable); the decoding headline keeps its real text in an `.sr-only` span; stat tiles use `role="group"` + `aria-label` with the animating spans `aria-hidden` (numbers appear only in the home page's stats strip, by the owner's choice); moving drawings beside page text have a Pause control.

## Architecture notes

- Panels (`.panel`) are pinned with GSAP ScrollTrigger (`pinSpacing: false`). A panel taller than the viewport pins at `bottom bottom`, so its content scrolls fully before the next panel covers it. Every panel needs an opaque background.
- The counters hold real numbers in the HTML and count up only with JS and motion allowed.
- Regenerating the ESTIC figures: `assets/estic-2026/make_figs.py` needs NumPy, SciPy and Matplotlib and writes all six PNGs into the current directory, so run it in a scratch directory and copy only the figure you changed. The originals were drawn with Matplotlib 3.11.2 and `text.hinting: no_hinting` (put it in a `matplotlibrc` and point `MATPLOTLIBRC` at its directory): with that setting five of the six regenerate pixel for pixel, so a corrected figure differs only where the data did. Then reduce each PNG to a 256-colour palette without dithering (Pillow: `quantize(colors=256, method=Image.Quantize.MEDIANCUT, dither=Image.Dither.NONE)`, saved with `optimize=True`), about a third of the bytes with no visible change.
- The footer year is set by `main.js` (`#copyright-year`, with a 2026 fallback).
