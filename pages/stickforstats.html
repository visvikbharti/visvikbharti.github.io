Advanced Statistics for Researchers

StickForStats is an open-source web platform that makes statistical assumption checking the default step before every analysis, not an optional extra. Its Guardian engine has eight validators (normality, variance homogeneity, independence, outliers, sample size, modality, linearity, homoscedasticity) and runs the relevant ones before a test executes. It reports the result alongside its assumption checks or, when a critical assumption fails, reroutes to an appropriate nonparametric alternative with a documented decision trail. A companion module re-checks the statistical claims in uploaded manuscripts.

Built to counter the assumption violations that drive irreproducible results, StickForStats runs on Django REST Framework and React with PostgreSQL, is MIT-licensed, and has been validated against SciPy and R. In the preprint, re-analysing a 91-sample synovial-sarcoma RNA-seq study (GSE271517) with Guardian moved 90.6% of 27,221 genes to a rank-based test and changed the differential-expression verdict for 553 of them. The code is on GitHub, and a Python SDK and command-line interface are on PyPI (pip install stickforstats).

Current Status: Preprint on bioRxiv (2026), DOI: 10.64898/2026.06.15.732278; in peer review at BMC Bioinformatics. First and corresponding author.

Platform Features

Assumption Validation (Guardian)

Before a test executes, Guardian runs the relevant subset of its eight validators in parallel and computes a composite confidence score. Critical violations reroute the analysis to an appropriate nonparametric alternative; an AI Statistical Advisor helps with test selection.

Educational Resources

Five curated biological example datasets with documented analysis vignettes. Early interactive Streamlit prototypes, such as the Confidence Intervals Explorer, explore statistical concepts through visualizations and simulations.

Power and Sample Size

Power and sample-size analysis for study design, with an optional 50-decimal-digit precision mode, plus effect sizes with confidence intervals.

Interactive Visualizations

Interactive charts built with Recharts, including forest plots for meta-analysis and volcano plots for differential expression.

Transparent Analysis

Reports assumption checks alongside every result, exports analyses as R or Python code, and offers Python and R SDKs for programmatic access.

Manuscript Review

Parses PDF, LaTeX and DOCX manuscripts, extracts their statistical claims and checks each one for internal consistency, with discipline profiles for CONSORT, STROBE, ICH-E9 and JARS-Quant.

Available Modules

Data Exploration & Visualization

  • Correlation Analysis (Pearson r, with Spearman's rho as the alternative when normality or linearity fails)
  • Interactive forest and volcano plots
  • Principal Component Analysis (PCA), an early Streamlit prototype
  • Probability Distributions explorer, an early Streamlit prototype

Hypothesis Testing

  • Tests checked by Guardian before they run (t-test, ANOVA, regression, chi-square)
  • Recommended Alternatives (Mann-Whitney U, Kruskal-Wallis, Spearman's rho, Welch's t-test, Welch's ANOVA)
  • Multiple Testing Correction (eight FWER and FDR methods, including Bonferroni, Holm-Bonferroni and Benjamini-Hochberg)
  • Power Analysis for sample size calculation
  • Effect sizes with parametric, bootstrap and noncentral confidence intervals

Biomedical Analyses

  • Per-gene differential expression with assumption checks and Benjamini-Hochberg FDR correction
  • Survival Analysis (Kaplan-Meier, Cox proportional hazards, log-rank test)
  • Meta-analysis (fixed and random effects, heterogeneity, Egger's publication-bias test)
  • Causal inference (propensity-score matching, inverse-probability weighting, difference-in-differences, mediation)

Educational Tools

  • Confidence Intervals Explorer, an early Streamlit prototype
  • Five curated biological example datasets with documented analysis vignettes

Who Benefits from StickForStats?

Experimental Biologists

Researchers conducting wet-lab experiments who need to analyze their data without extensive statistics training. StickForStats helps with experimental design, sample size calculation, and appropriate statistical analysis of results.

Example: A molecular biologist comparing gene expression changes across multiple treatment conditions can use StickForStats to check each test's assumptions, switch to a nonparametric alternative where they fail, and correct for multiple testing.

Clinical Researchers

Medical professionals conducting clinical studies who need robust statistical methods for patient data. StickForStats provides tools for survival analysis, meta-analysis, causal inference, and manuscript review against CONSORT and ICH-E9.

Example: A clinical researcher studying drug efficacy can use StickForStats to perform power analysis for study design, adjust for confounding with methods such as propensity-score matching, and check the manuscript's statistics before submission.

Graduate Students

Students in biology, medicine, and related fields who need to analyze their thesis data but lack formal statistical training. StickForStats serves as both an analysis tool and an educational resource.

Example: A PhD student can see which assumptions each test needs and whether their data meet them, work through the documented analysis vignettes, and export the analysis as R or Python code.

Technology Stack

Frontend

  • React 18: User interface
  • Material-UI 5: UI components
  • Recharts: Interactive visualizations, including forest and volcano plots
  • jStat: Client-side computations

Backend

  • Python 3.11, Django 4.2 and Django REST Framework: Application layer with Guardian integration
  • NumPy/SciPy: Array operations and statistical functions
  • statsmodels: Regression diagnostics and GLMs
  • lifelines: Survival analysis
  • scikit-learn: Machine learning utilities
  • mpmath: Optional 50-decimal-digit precision mode
  • Celery with Redis: Long-running analyses

Deployment

  • Docker and Docker Compose: Containerized deployment of the full stack
  • PostgreSQL 15 and Redis: Relational storage, caching and task queues
  • GitHub Actions: CI running more than 1,500 automated tests on every commit
  • PyPI: Python client SDK and command-line interface
  • Streamlit Cloud: Hosting the early standalone prototypes

Project Vision

StickForStats aims to democratize advanced statistical analysis by making complex methods accessible to researchers of all backgrounds. Our vision includes:

  • Reducing the statistical knowledge barrier by checking assumptions automatically and guiding users to an appropriate analysis
  • Improving reproducibility in research by providing standardized analysis workflows and transparent code
  • Building statistical literacy in the scientific community through integrated learning resources
  • Creating a platform for collaboration where researchers can share and build upon analytical approaches
  • Supporting open science principles by making the entire platform open-source under the MIT license

We believe that by making advanced statistical tools more accessible, we can help researchers focus on their scientific questions rather than struggling with statistical methods, ultimately accelerating discovery and improving research quality.
