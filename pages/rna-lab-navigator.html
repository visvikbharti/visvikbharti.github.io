RNA Lab Navigator

Retrieval-augmented research assistant for fast, grounded literature triage in a wet-dry lab

GitHub

Laboratory Knowledge Management

RNA Lab Navigator is a sophisticated AI-powered Retrieval-Augmented Generation (RAG) system designed specifically for RNA biology laboratories. It addresses the critical challenge of knowledge fragmentation in research environments where valuable insights are scattered across theses, papers, protocols, and experimental notes.

Researchers query internal lab documents and the primary literature in natural language and receive answers with citations to the source documents, for fast, grounded literature triage in a wet-dry lab. It is in routine use by about 21 researchers.

Intelligent Q&A System

Natural language queries answered with citations from your lab's documents

Technical Architecture

The system employs a modern microservices architecture with clear separation of concerns, enabling scalability, maintainability, and security.

Frontend (React + TypeScript)

  • Modern React 18 with TypeScript for type safety
  • Redux Toolkit for state management
  • Material-UI for consistent, responsive design
  • Real-time updates via WebSocket connections
  • Progressive Web App capabilities

Backend (Django + DRF)

  • Django 4.2 with Django REST Framework
  • JWT authentication with refresh token rotation
  • Celery for asynchronous task processing
  • Redis for caching and session management
  • Comprehensive API documentation with Swagger

AI/ML Pipeline

  • OpenAI GPT-4 for response generation
  • Ada-002 embeddings for semantic search
  • Weaviate vector database with HNSW indexing
  • Hybrid search combining semantic and keyword matching
  • Cross-encoder reranking for accuracy

Infrastructure

  • Docker containerization for all services
  • PostgreSQL for relational data
  • Nginx reverse proxy with SSL termination
  • GitHub Actions for CI/CD pipeline
  • Comprehensive monitoring and logging

Advanced RAG Implementation

The heart of RNA Lab Navigator is its sophisticated Retrieval-Augmented Generation system, designed to deliver accurate, contextual responses grounded in the lab's documents.

1. Document Processing

Intelligent ingestion pipeline handling PDFs, DOCX, and other formats

2. Smart Chunking

Context-aware text segmentation preserving semantic integrity

3. Embedding Generation

4. Hybrid Retrieval

Combining semantic and keyword search for optimal results

5. Response Generation

Context-aware answers with accurate citations

Access & Security

Protecting sensitive research data is paramount. RNA Lab Navigator uses JWT-based authentication, and access is limited to lab members on the institute network.

Authentication & Authorization

  • JWT tokens with 15-minute access token lifetime
  • Refresh token rotation for enhanced security
  • Brute-force protection (Axes)

Network Access

  • Served on the institute network
  • Access limited to lab members

Deployment Challenges & Solutions

The journey to production involved navigating complex technical challenges across multiple deployment platforms, ultimately resulting in a local deployment on the institute network.

Platform Evaluation

Evaluated Railway, Render, PythonAnywhere, and Vercel for hosting, each presenting unique constraints.

CORS & Authentication

Resolved complex cross-origin resource sharing issues between distributed services. Implemented dynamic CORS configuration to handle Vercel's changing deployment URLs while maintaining security.

Performance Optimization

Cut response times through strategic caching, connection pooling, and query optimization, and by reducing context chunks from 3 to 2.

Local Deployment Success

Successfully deployed on institute network using Docker containers on local MacBook, serving 25 documents (7 PhD theses, 18 papers) to lab members. System accessible at institute IP addresses.

Engineering Insights

Deployment Platform Selection

Free tier limitations significantly impact architecture decisions. Evaluating multiple platforms (Railway, Render, PythonAnywhere) taught valuable lessons about balancing cost, features, and performance requirements.

RAG System Optimization

Balancing accuracy with performance requires careful tuning. Reducing context chunks from 3 to 2 improved response times.

Security vs Usability

Implementing robust security without hampering user experience requires thoughtful design. Token refresh mechanisms improved both security and usability.

User-Centered Development

What developers think users need often differs from actual requirements - continuous feedback loops are essential.
